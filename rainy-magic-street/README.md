# 雨夜魔法街区 · 街角微缩场景

一个**单文件、可双击打开**的三维微缩景观：日式魔法街区街角，复古魔法杂货铺 + 法师塔，雨夜，三渲二（卡通渲染）。
第三人称自由观看——拖拽旋转、滚轮缩放、右键/双指平移，无任何 UI 元素。

> 与「雨夜便利店」共用同一套引擎（三渲二管线、静态几何合并、显卡档位、自适应画质、构建与验证流程），
> 本项目只重写内容层：调色板与贴图、地面、店铺、道具、邻栋。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `index.html` | **本地版成品**。自包含单文件（约 617 KB，three.js 已内联），双击即可打开 |
| `dist/` | **部署版产物**（`index.html` + `assets/app.js` + `_headers`） |
| `src/` | 源码（source of truth） |
| `build.mjs` | 构建脚本：一次产出上面两种形态 |
| `preview/` | 多角度效果图 |
| `.devtools/` | 本地验证与推送辅助脚本（不参与构建） |

## 重新构建

```bash
npm install
node build.mjs          # 生成 index.html（单文件）与 dist/（拆分）
```

## 引擎要点

- **三渲二**：MeshToonMaterial + 4 段 gradientMap；反向外壳描边（沿法线外扩，屏幕宽度近似恒定）。
- **湿滑地面**：底层 Reflector 镜面 + 上层半透明沥青（alphaMap 控积水区域透出镜面）+ 加色反光条。
- **雨**：GPU 实例化雨丝（视图空间恒宽），自动避让店体与雨棚；另有向上飘的魔法浮游光尘层。
- **后期**：UnrealBloom + 调色（对比/饱和/紫调暗部/暗角）+ ACES 色调映射。
- **性能**：静态几何合并（按材质 + renderOrder）、材质实例去重、阴影只渲一次、镜面按档位降规格并降频、
  着色器异步并行编译、点光源约 10 盏、自适应画质阶梯 + 像素预算、显卡档位三档。

## 常用调整位置

- 取景：`src/main.js` 中 `HOME`
- 亮度/氛围：`src/main.js` 中 `toneMappingExposure`、`hemi`、`moon`、`scene.fog`、天空 uniforms、`GradeShader`
- 画质档位：`src/main.js` 中 `TIER_CFG`
- 店铺与街道尺寸：`src/layout.js`
- 彩色玻璃通透度：`src/store.js` 中 `stainedMat.opacity`
