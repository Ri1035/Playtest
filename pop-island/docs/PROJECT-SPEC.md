# PROJECT-SPEC.md — 项目定位、产品目标与功能范围

## 项目定位

POP ISLAND（波普岛）是一款**波普艺术风格的 Web 2D 小岛收集小游戏**，零安装、零素材依赖，打开即玩。面向休闲玩家，单次会话时长 1-5 分钟，适合碎片时间与传播分享。

## 产品目标

1. 以波普艺术作为可感知的差异化视觉卖点。
2. 极低上手成本：一个移动键 + 一个目标（收集），10 秒内学会。
3. 提供轻量成长循环：连击追求 → 涂色升级 → 难度与配色变化，形成"再来一把"动力。
4. 全平台可玩：桌面键盘 + 移动端触屏；低端设备也能流畅运行（Canvas 2D + 离屏图层缓存）。

## 玩法规则（v0.1.0 数值口径）

| 项 | 规则 |
| --- | --- |
| 移动 | 玩家速度 265 px/s，限制在岛屿内（半径函数判定） |
| 收集得分 | 元素基础分 10（汽水罐/甜甜圈/冰淇淋为 15）× 连击倍率 |
| 连击 | 3.5 秒内连续收集 +1 连击（上限 x9）；倍率 = `0.5 + 连击 × 0.5`，即 x1→1.0，x2→1.5 … x9→5.0 |
| 涂色条 | 每次收集 +`6 + 等级`，满 100 升级 |
| 升级 | 等级 +1，切换调色板，元素目标数 +2、海鸥上限 +1（上限 8）、生成提速；触发冲击波清除 320px 内海鸥并冻结全场 2s |
| 海鸥 | 巡逻游荡；玩家进入 210px 追击（速度 1.2 倍）；碰撞重置连击 + 1.5s 无敌 |
| 道具 | 磁铁（5s 吸附 190px 内元素）、冰冻（4s 全场海鸥冻结）；生成概率各 5% |
| 元素目标数 | `5 + 等级 × 2`，定时补位 |
| 死亡/结算 | 无死亡设计；碰撞只重置连击，最高分本地持久化 |

## 功能范围

**包含**：菜单、游戏主循环、暂停/继续/重开、最高分、音效开关、触屏摇杆、升级遮罩、受击反馈。

**不包含（v0.1.0）**：多关卡地图、存档系统、联网排行、内购、PWA、音频素材文件、服务端任何能力。

## 成功标准

- 首帧到可玩 < 2s（本地与 Pages 部署后均可）
- 桌面与移动端均无操作阻塞
- 单局可无限持续（数值有界：海鸥上限 8、连击上限 x9、速度随等级有上界）
- 全部素材程序化生成，无任何外部资源请求失败风险
