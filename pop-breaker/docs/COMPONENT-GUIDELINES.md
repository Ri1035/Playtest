# COMPONENT-GUIDELINES.md — 组件开发、样式、依赖与无障碍规范

## 模块划分

| 模块 | 职责 | 约定 |
| --- | --- | --- |
| `engine.js` | 状态与规则 | 不直接操作 DOM；通过 `ui` 桥更新界面 |
| `sprites.js` | 绘制 | 纯函数，输入状态输出 Canvas 绘制 |
| `levels.js` | 数据 | 纯数据，不引入逻辑 |
| `audio.js` | 声音 | 惰性创建 AudioContext，首次用户手势解锁 |

## 样式规范

- 颜色常量集中在 `:root` CSS 变量与 PALETTES
- 粗描边（3-5px 黑色）、硬阴影（4-8px offset）、圆角（5-18px）统一风格
- 不使用 emoji；图标一律内联 SVG 或 Canvas 绘制
- 响应式：画布等比缩放，窄屏精简 HUD

## 依赖规范

- 运行时零外部依赖（无 CDN 资源、无图片音频文件）
- 构建期仅 Vite

## 无障碍

- 所有按钮有真实事件绑定（禁止僵尸按钮）
- 触屏目标 ≥ 40px，支持触摸拖动
- 键盘可完成全部操作（方向键 / 空格 / P / M）
