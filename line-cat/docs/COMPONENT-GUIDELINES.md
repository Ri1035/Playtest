# COMPONENT-GUIDELINES

组件开发、样式、依赖与无障碍规范。

## 组件清单

| 组件 | 选择器 | 职责 |
| --- | --- | --- |
| 标签按钮 | `.tab` | 切换坐姿 / 站姿视图 |
| 舞台 | `.stage` | 容纳标签与猫图 |
| 视图 | `.view` | 单个造型的 SVG 容器，互斥显示 |
| 猫 SVG | `.cat-svg` | 内联矢量图形（mask + 分层） |
| 控制面板 | `.panel` | 图层、动画、速度与重播控件 |
| 复选行 | `.row input[type=checkbox]` | 图层 / 动画开关 |
| 速度滑块 | `#speed` | 0.5–2x 速率 |
| 重播按钮 | `#replay` | 重新播放描边开场 |

## 样式约定

- 无预处理器；以类选择器组织，避免过深嵌套与高优先级相互抵消。
- 颜色、尺寸用语义 token（见 DESIGN.md）；同类数值保持统一。
- 变换元素统一 `transform-box: view-box`，原点在视图数据属性中维护。
- 隐藏图层用 `.off { display:none }`；状态切换即时生效。

## 依赖策略

- 优先原生能力；确需第三方库时选择成熟、开源、轻量者。
- 依赖 vendored 到 `assets/vendor/`，文件名含版本或在文档记录版本、来源、许可证。
- 运行时不引用外网 CDN，保证离线与部署后稳定。
- 若后续引入 CDN，统一走 jsDelivr，备用 cdnjs；禁用来源不明或有投毒历史的镜像。

## JavaScript 约定

- 原生 ES5 风格编写（兼容面广），IIFE 隔离作用域，不污染全局。
- 命名语义化；状态以普通对象 / DOM 属性持有，重渲染式更新。
- 每个可点元素必须绑定真实行为，禁止僵尸按钮。
- 事件监听与定时器在重播 / 切换时正确清理，避免泄漏与重复触发。

## 无障碍

- 所有交互元素键盘可达，`:focus-visible` 提供可见焦点。
- 触控目标 ≥ 44×44px；图标 / 复选控件尺寸不小于 20px。
- SVG 提供 `role="img"` 与 `aria-label`；装饰性元素对辅助技术隐藏。
- 动画遵循 `prefers-reduced-motion`；不以颜色作为唯一信息载体。
- 文本与背景对比满足可读性；正文不小于 14px。

## 新增组件检查清单

1. 语义化命名与结构，样式接入现有 token。
2. 具备真实交互与即时反馈，无死控件。
3. 键盘可达、焦点可见、触控区足够大。
4. 在桌面与移动断点下无溢出 / 裁切。
5. 通过页面截图核对实际渲染。
