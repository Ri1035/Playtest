# CHANGELOG

本项目版本记录。格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)。

## [0.1.0] - 2026-10-07

### 新增

- 波普艺术风格小岛：程序化绘制沙滩、草地、网点海面、棕榈树、花朵、岩石、汽水罐
- 玩家角色：WASD / 方向键移动，触屏虚拟摇杆
- 收集玩法：8 种波普元素（星、樱桃、香蕉、嘴唇、花、汽水罐、甜甜圈、冰淇淋），支持磁铁吸附
- 连击系统：3.5 秒窗口内连续收集，倍率最高 x5
- 涂色升级系统：4 套波普配色循环，升级触发"波普冲击波"清除附近海鸥
- 敌人系统：海鸥巡逻 + 追击 AI，被撞重置连击并获得短暂无敌
- 道具系统：磁铁（吸引元素）、冰冻（冻结海鸥）
- WebAudio 程序化合成音效：收集 / 撞击 / 升级 / 道具，支持静音持久化
- 粒子特效、飘字、屏幕震动、等级与受击遮罩动画
- 最高分本地持久化（localStorage）
- 暂停 / 继续 / 重新开始，页面失焦自动暂停
- 响应式适配桌面与移动端

### 基础设施

- GitHub 仓库 + Cloudflare Pages 部署链路
