# POP ISLAND · 视觉与交互设计规范

本文件是视觉决策的唯一依据。任何新增界面元素都必须先符合本规范。

## 一、设计信条

波普艺术不是"色彩鲜艳"，而是**模拟商业印刷的机械感**。三条硬规则：

1. 一切明暗关系由网点承担，不用渐变
2. 一切形体边界由粗黑线承担，不用柔和过渡
3. 一切情绪由拟声词承担，不用写实动画

违反任意一条，画面立刻退化为普通扁平化 UI。

## 二、调色板

定义于 `src/render/palette.js`，不在 CSS 或其他模块重复定义。

### 基色

| 名称 | 值 | 用途 |
| --- | --- | --- |
| INK | `#141414` | 所有描边、投影、文字 |
| PAPER | `#fff6e9` | 页面底色、留白区域 |

### 四色印刷基色

| 名称 | 值 | 对应 CMYK |
| --- | --- | --- |
| cyan | `#00c2e0` | C |
| magenta | `#ff2d78` | M |
| yellow | `#ffd400` | Y |
| green | `#3ddc6b` | 派生 |

### 扩展色

`greenDeep #1f9c4a`、`yellowDeep #e0a800`、`orange #ff7a1a`、`purple #8a4fff`、`brown #a9713c`。

**规则**：纯色平涂区只用基色与扩展色。任何 `rgba()` 仅允许用于描边与投影，且 alpha 不低于 0.16。

## 三、Ben-Day 网点系统

实现于 `src/render/patterns.js`。

### 原理

网点以固定间距与固定半径铺排，在视觉上把单一颜色"叠印"成另一种颜色。这是 1879 年 Benjamin Day 申请的商业印刷工艺，Roy Lichtenstein 于 1961 年将其放大为艺术语言。

### 参数约束

| 参数 | 取值 | 偏离后果 |
| --- | --- | --- |
| 点半径 | 2.3–2.6 px | <2px 缩放后消失；>3px 糊成实色 |
| 点间距 | 8–9 px | 过大显稀疏，过密失去"印刷"质感 |
| 覆盖透明度 | 0.55–0.62 | <0.25 不可见；>0.55 失去网点纹理 |

**这是最容易做坏的一环。** 修改网点参数后必须重新截图确认，不能只看代码。

### 图案缓存

图案在离屏 canvas 烘焙一次，存入模块级 `Map` 后作为 `CanvasPattern` 复用。缓存键必须包含全部视觉参数，否则不同地形会互相串色。

## 四、描边与投影

```css
--border: 4px solid var(--ink);
--shadow: 5px 5px 0 var(--ink);
```

- 描边宽度：界面元素 4px，Canvas 图形 2–3px，气泡 3px
- 投影**必须**为 0 模糊的硬偏移，禁止 `box-shadow: 0 0 8px`
- 描边颜色恒为 INK，不随底色变化

## 五、版式

### 字体

`"Arial Black", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`

标题与数值用 `Arial Black` 模拟粗体漫画字；中文回退到系统黑体。**不使用**任何需要网络加载的字体。

### 层级

1. Logo：双色块并置，整体旋转 `-2deg`
2. HUD 数值：`20px`，等宽右对齐
3. 正文与提示：`13–15px`
4. 按钮标签：`13px`

### 间距

统一 4px 基准栅格。常用间距：8px（组件内）、10px（组件间）、14px（区块间）。

## 六、交互反馈

任何可点击元素必须给出**三种**反馈中的至少两种：

1. **形变**——`translate` 硬位移 2–3px，投影同步缩短
2. **视觉**——底色切换为洋红（选中态）或灰色（不可用态）
3. **音效**——方波音，参数见 `src/ui/audio.js`

禁用态：`.unaffordable` 灰底 + 灰字，保留描边。

悬停态：`.build-btn:hover` 位移 `-2px`，投影增至 `6px 6px`。

按压态：`translate(2px, 2px)`，投影缩至 `1px 1px`。**禁止**使用 `transition: ease`，仅允许 `steps()`，以保持机械感。

## 七、Canvas 图形规范

- 描边：`lineWidth 2–3`，`lineJoin/lineCap: round`
- 阴影：硬边椭圆，`rgba(20,20,20,0.22)`，禁止高斯模糊
- 动画：`sin` 正弦缩放（振幅 0.035），模拟漫画抖动，不使用缓动函数
- 文字：粗描边包裹（`lineWidth 4` + `PAPER` 色 stroke）保证任意底色可读

## 八、可访问性

- 交互元素均为原生 `button`，可 Tab 聚焦
- `:focus-visible` 使用 3px 紫色描边，与波普配色不冲突
- 状态提示区 `role="status" aria-live="polite"`，游戏事件自动播报
- 尊重 `prefers-reduced-motion`：关闭过渡效果
- 颜色不作为唯一信息载体——不可建造时同时绘制叉号，不可用时同时显示"材料不足"文案

## 九、禁止事项

- ❌ 渐变（`linear-gradient` / `radial-gradient` 填充）
- ❌ 模糊阴影
- ❌ 圆角超过 6px
- ❌ 半透明彩色叠加模拟色调
- ❌ 外部字体、图片、音频文件
- ❌ 页面出现生成工具署名或水印
