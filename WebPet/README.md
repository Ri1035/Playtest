# 喵喵跟随 · Cat Follow

> 抽帧序列动画 + 鼠标跟随互动页面：移动鼠标，一只小猫会一路小跑跟着你；点击它，它会跳一下。

## 项目简介

喵喵跟随是一个纯前端 Canvas 互动小页面。页面加载一组抽帧序列精灵图，渲染出一只会小跑的小猫：小猫会跟随鼠标 / 触摸位置移动，点击小猫还会触发跳跃。侧边设置面板可调节跟随灵敏度、大小、影子与残影，适合作为前端交互动效的轻量示例。

## 主要功能

- 抽帧序列动画：小猫随跟随状态切换小跑动画，流畅自然
- 鼠标 / 触摸跟随：小猫朝光标方向一路小跑，支持移动端触屏
- 点击互动：点击小猫触发跳跃动作
- 侧边设置面板：跟随灵敏度、小猫大小、落地影子、运动残影随时调节
- 加载页实时显示抽帧序列加载进度

## 快速开始

用浏览器直接打开 `index.html` 即可；也可放到任意静态服务器上访问。

## 技术栈

- 原生 HTML / CSS / JavaScript
- Canvas 2D 渲染
- 抽帧序列（精灵图帧动画）
