# AGENTS.md — 项目协作与代码开发规范

## 开发准则
- 开工前先检索开源方案、免费资源、现有 skills 或提示词，避免闭门造车；仅对复杂或陌生任务检索 1-2 轮，简单任务直接开工。
- 一次只完成指定任务，不擅自扩展范围、不改动任务外文件。
- 代码规范：命名语义化、格式统一；项目默认公开。
- 去除一切 AI 水印与生成痕迹：页面与代码、注释中不留任何 AI 署名或"由 AI 生成"类标识。
- 每次完成后自验证并报告构建 / 验证结果。
- Git 规范提交、小步提交；版本管理与日志记录（CHANGELOG.md）必须在每次任务结束前检查更新。
- 项目经 GitHub 管理、Cloudflare Pages 部署。
- README 只做项目介绍，不放核心信息；重要文件下沉到 docs/。
- 默认直接执行，不反复请示；仅当操作不可逆、影响账户或他人数据、或超出任务范围时先询问。
- 禁止臆造功能、跳过验证或假装完成。

## 提交规范
- 提交信息格式：`type: 简述`（type ∈ feat / fix / docs / chore / refactor / style）。
- 每个提交只包含一个逻辑变更；锁文件与代码分离提交。
- 作者信息：`Ri1035 <koka2996978242@outlook.com>`。

## 验证闭环
- 构建：`npm run build`（Vite，产物 `dist/`）。
- 本地预览：`npm run preview` 后浏览器实测核心流程（菜单 → 开始 → 发球 → 反弹 → 击砖 → 连击 → 过关 → 结束）。
- 发布前自查：无水印关键词、`dist/` 无外链、无 token 泄漏。
