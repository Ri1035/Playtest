# DESIGN.md — 波普视觉与交互设计规范

本文件定义 POP ISLAND 的视觉风格、布局与交互设计规则，是新增素材与 UI 的唯一设计依据。

## 设计理念

以**波普艺术（Pop Art）**为核心语言：把日常元素（食物、罐子、嘴唇、星星）抽离、放大、纯色化，用漫画式的粗描边和网点（half-tone / Ben-Day dots）制造"印刷品"质感。整体情绪：高饱和、响亮、幽默、不精致但强烈。

## 色彩系统

主色（全局固定）：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 墨色 | `#111111` | 描边、文字、硬阴影 |
| 波普红 | `#FF3B30` | 主按钮、角色身体、强调 |
| 波普黄 | `#FFD166` | 按钮、星、高亮 |
| 波普蓝 | `#2B7AFF` | 海面、次级强调 |
| 纸色 | `#FFF4E0` | 面板底色、角色脸 |

关卡调色板（4 套循环，定义见 `src/game/sprites.js` 的 `PALETTES`）：

1. 经典红黄蓝（红海、黄沙）
2. 蓝绿橙（青蓝海、橙沙）
3. 紫粉绿（紫海、黄沙）
4. 黑白金（墨海、米白沙）

规则：同一关卡内所有图层（海、沙、草、角色身体）必须取自同一套调色板；新增调色板必须保持"海 / 海网点 / 沙 / 亮沙 / 草 / 草网点 / 身体 / 头发 / 脸 / 强调"十个槽位完整。

## 线条与造型规则

- **粗黑描边**：所有实体（角色、元素、敌人、装饰、UI 按钮）必须有 `#111111` 描边，线宽与尺寸成正比（约尺寸的 10-14%）。
- **双描边**：岛屿轮廓采用"黑 12px 外 + 白 5px 内"双层描边，制造漫画压印感。
- **硬阴影**：UI 用 `box-shadow: 4px 4px 0` 硬偏移阴影，不用模糊阴影；游戏内影子用半透明黑椭圆。
- **禁止渐变滥用**：颜色过渡一律用网点密度变化表达，不用 smooth gradient（UI 背景的 radial-gradient 网点例外，见下）。
- **网点（half-tone）**：海面、草地、按钮背景用确定性网点（`halftoneRect`，偏移由坐标哈希决定，保证逐帧稳定）。

## 字体

- 标题/按钮：`Impact` / `Arial Black`（Windows 系统字体，零外部依赖），粗描边 + 硬阴影。
- 正文：`Arial Black` 系回退到中文字体。
- 不引入网络字体（离线可玩优先）。

## 布局

- 单页全屏：`#game-wrap` 铺满视口，Canvas 占满。
- HUD 层级（z-index）：canvas(0) < HUD(1) < 暂停(20) < 受击遮罩(29) < 升级遮罩(30)。
- HUD 布局：左上分数/最高分，顶部居中连击徽章，底部居中涂色条，右上音效按钮。
- 主菜单：居中纵向排列（大标题 → 副标题 → 玩法说明 → 开始按钮 → 操作提示 → 最高分）。

## 动效

- 相机：跟随玩家，lerp 系数 5，clamp 到世界边界。
- 收集物：正弦上下浮动。
- 连击徽章：弹出缩放动画 `combo-pop`（180ms）。
- 受击：屏幕震动（0.4s / 幅度 12）+ 红色遮罩渐隐 + 角色无敌闪烁。
- 升级：黄色大字遮罩 `level-pop`（1.4s）+ 波普冲击波粒子。
- 飘字：向上漂移 + 轻微放大，黑色粗描边。

## 交互规范

- 键盘：WASD / 方向键移动，P / Esc 暂停；游戏进行中阻止方向键与空格滚动页面。
- 触屏：左侧任意按下处生成虚拟摇杆（基座半径 46，摇杆行程 52），松手消失。
- 指针类型：摇杆仅响应 `touch` 类型指针，鼠标不干扰。
- 失焦 / 页面隐藏：自动暂停。
- 无障碍：所有按钮带 `aria-label` / 可见文本；连击与分数变化有视觉反馈（不只靠颜色）。

## 动效可访问性

- 动效均为短促非循环（除粒子瞬态），不依赖用户主动触发才停止；后续如加入常驻循环动画需提供"减少动效"开关。
