## 下一步

按优先级排列。

### P1 — 玩法深度

- [ ] **建筑升级**：状态中已有 `level` 字段与效率加成公式，缺升级入口与升级消耗
- [ ] **建筑拆除**：返还部分材料，避免玩家铺错后无法调整
- [ ] **灯塔主动技能**：每 15 秒向下一次"灵感雨"，全场建筑产出翻倍 10 秒
- [ ] **岛屿扩张**：消耗晶石将网格从 22×22 扩展至更大尺寸

### P2 — 体验完善

- [ ] **触屏适配**：移动端点击建造与悬停反馈不匹配
- [ ] **首次引导**：新玩家不知道要采集资源才能建造
- [ ] **成就系统**：波普风格的奖章展示
- [ ] **音效持久化**：跨会话保留开关状态

### P3 — 视觉增强

- [ ] **昼夜循环**：影响配色与产出效率，强化岛屿氛围
- [ ] **居民角色**：小型波普人物在岛上走动
- [ ] **天气效果**：雨天的斜线纹理变化

## 已考虑但暂不做

- **多人联机**：与单机经营定位不符，投入产出比低
- **建筑拆除返还 100%**：会削弱规划决策的意义
- **接入账号系统**：轻度休闲游戏不值得引入后端复杂度

## 技术债

| 项| 说明 | 影响 |
| --- | --- | --- |
| `main.js` 偏大 | 装配逻辑、HUD、事件处理集中在一个文件 | 继续增长后可读性下降，届时拆分为 `hud.js` 与 `input.js` |
| 测试依赖手写 DOM | `.devtools/test-interaction.html` 复制了一份页面结构 | index.html 结构变动时需同步维护两份 |
| 无 CI | 测试需手动执行 | 后续接入 GitHub Actions 或 Cloudflare Pages 构建校验 |
