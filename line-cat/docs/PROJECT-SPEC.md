# PROJECT-SPEC

项目定位、产品目标与功能范围。

## 背景

原始素材为黑白线稿小猫（坐姿、站姿两张图）与一段约 8 秒的动画视频（坐姿猫慢眨眼 + 轻微呼吸，帧底部带淡灰投影）。目标是将其转为纯白底、黑线、无阴影的矢量动画，并保持元素分层、便于后续编辑。

## 项目定位

一个纯静态、单页的线稿小猫矢量动画作品：

- 造型直接来自图像描摹生成的 SVG 路径，不手工重绘。
- 用成熟开源动画库编排，而非堆砌手写关键帧。
- 无后端、无框架、无构建步骤，打开即用。

## 产品目标

1. 还原素材造型与动态：描边开场、呼吸、眨眼。
2. 结构清晰、分层语义化，使非作者也能快速理解并修改。
3. 可在 GitHub 上版本管理，并通过 Cloudflare Pages 公开访问。

## 目标用户

- 希望直接欣赏 / 嵌入该动画的访问者。
- 需要在此基础上二次编辑（改造型、加动作、换部件）的开发者或设计者。

## 功能范围

### 包含

- 坐姿、站姿两个造型的标签切换。
- 手绘描边开场动画。
- 呼吸、身体微摆、随机间隔眨眼的循环动画。
- 六图层显隐开关、动画开关、速度调节、重播。
- 响应式布局、键盘可达、reduced-motion 兜底。

### 不包含（当前版本）

- 尾巴、耳朵、头部的独立动画（路径未分层，见 TODO）。
- 视线跟随、音效、更多姿势、PWA / 深色模式。
- 任何后端、账号、数据存储能力。

## 验收标准

- 造型与描摹 SVG 一致；纯白底黑线、无阴影文字。
- 开场与循环动画在 Chromium / Edge 下实时正确呈现。
- 桌面与移动端无溢出、裁切；控制台无错误。
- 代码与页面无 AI 水印、无凭据泄露。
