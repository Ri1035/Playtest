# DESIGN.md — 视觉风格、布局与交互设计规范

## 设计理念：波普艺术（Pop Art）

- 高饱和撞色（红 / 黄 / 蓝 / 粉 / 绿），大面积纯色块
- 半调网点（Ben-Day dots）填充与背景
- 粗黑描边（3-5px）、硬阴影（offset 色块）、无渐变过渡（背景除外）
- 漫画拟声词（POP! / BAM!）作为得分飘字
- 一切视觉素材程序化绘制，无外部图片

## 配色

每关一组配色（`src/game/levels.js` PALETTES），按关卡轮换：
- 经典红黄蓝 / 粉蓝泡泡 / 紫绿派对 / 霓虹柑橘 / 黑白金章

## 布局

- 画布：960×640 逻辑分辨率，容器等比缩放
- HUD 顶部悬浮：得分、连击、关卡、生命、最高分、暂停与静音
- 菜单 / 结束为半透明全屏遮罩 + 波普卡片

## 交互

- 鼠标 / 触摸拖动挡板；左右方向键也可操控
- 点击或空格发球；P / Esc 暂停；M 静音
- 反馈：击砖弹跳音、连击倍率飘字、砖块爆裂粒子、道具效果广播

## 无障碍与适配

- 按钮均为真实可点击元素，非僵尸按钮
- 移动端触控拖动生效，窄屏 HUD 自动精简
