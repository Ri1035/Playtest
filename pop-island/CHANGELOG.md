# 更新记录

本文件记录 POP ISLAND 的版本变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0] — 2026-10-07

首个可运行版本。

### 新增

- **岛屿生成**：基于分形噪声（5 阶fBm + 径向衰减）生成 22×22 地形，含深海、浅滩、沙滩、草地、森林、岩地六类地貌；3 轮 cellular 平滑消除锯齿；在岛屿质心自动开辟 3×3 建造区
- **Ben-Day 网点系统**：离屏 canvas 烘焙圆点与斜线图案，按缓存键复用为 `CanvasPattern`；实现 1879 年商业印刷工艺的平涂叠印效果
- **五种建筑**：波普小屋、风车工坊、采石场、炼色厂、波普灯塔，各含独立矢量绘制与动画
- **玩法闭环**：建造扣料、资源采集、连击计数与人口增长、每 2 秒生产结算、灯塔等级效率加成
- **漫画特效层**：12 角星形拟声词气泡（POW!/BAM!/ZAP!）、资源飘字、水面涟漪
- **程序化音效**：WebAudio 方波合成，四种音色，无音频文件
- **存档**：localStorage 持久化，每 20 秒自动保存；损坏数据安全降级为新档
- **响应式渲染**：DPR 适配、等比缩放居中、悬停高亮（可建造青色虚线框 / 禁止洋红叉号）
- **开发期自检**：14 项逻辑单元测试 + 22 项浏览器交互断言 + 精灵检视页

### 技术决策

- 采用原生 ES Module + Canvas 2D 零依赖方案，不引入游戏引擎或美术素材库
- 全部美术由代码程序化绘制，项目不含任何图片、字体、音频文件
- 地形静态内容烘焙为离屏 canvas，每帧仅一次 blit

### 已知限制

- 无建筑升级交互：`level` 字段与效率加成已实现，尚缺升级入口
- 仅支持鼠标操作，未适配触屏手势
- 无音效开关状态持久化到跨设备（仅本地 localStorage）
