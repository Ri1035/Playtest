# 项目定位与功能范围

## 一句话定位

一款以波普艺术为视觉语言的 2D 浏览器小岛经营游戏，用网点与拟声词重绘经典像素模拟经营。

## 目标玩家

- 喜欢轻度经营玩法、5–15 分钟一局的休闲玩家
- 对波普艺术、复古漫画、丝网印刷风格有审美兴趣的用户
- 追求"打开就能玩、随开随关"体验的碎片时间玩家

## 产品目标

### 核心目标

1. **零门槛上手**——打开页面即进入游戏，无需注册、教程弹窗或设置项
2. **视觉即卖点**——第一眼就能认出是波普艺术，而非"一个用彩色的普通小游戏"
3. **完整的成长曲线**——采集 → 建造 → 扩张 → 更高级建筑，每 10 分钟有可见进展
4. **随时中断**——自动存档，关页不丢进度

### 非目标

- ❌ 付费点、抽卡、广告等商业化设计
- ❌ 排行榜、社交、UGC 分享
- ❌ 需要服务器的状态同步

## 视觉定位

严格遵循 Lichtenstein 式波普语言，完整规范见 `DESIGN.md`。核心三要素：

1. **Ben-Day 网点**——一切明暗关系的唯一来源
2. **平涂原色**——青、洋红、黄，无渐变
3. **漫画语汇**——粗黑描边、硬投影、拟声词

## 技术约束

- 纯静态站点，无构建步骤
- 零运行时依赖
- 无图片、字体、音频等二进制素材——全部程序化生成
- 目标：首屏加载 < 100KB（gzip 后 < 30KB）

## 商业模式

无。开源作品，不含任何商业化元素。
