# 文字绳子交互效果（Text Rope Effect）

> 把一段文字变成一条可拖拽的「物理绳子」：文字像绳子一样串联，拖拽任意字符把整串拉散；按 `F` 让文字在重力下自然散落，按 `R` 缓动飞回原位。纯原生、零依赖、单文件即开即用。

## ✨ 项目简介

这是一个基于 Verlet 物理积分的文字绳子交互演示。字符沿蛇形（Zig-Zag）排布，物理连接顺序与视觉阅读顺序分离，字符间用 SVG 连线实时跟随。拖拽任意字符会像拉绳子一样把整串拉散，拉得太远还会连锁解锁相邻字符。整段效果集中在单个 `index.html`，无需安装、无需构建。

## 🚀 特性亮点

| 维度 | 说明 |
| --- | --- |
| 物理模拟 | Verlet 积分 + 距离约束迭代，保持「绳子连接感」 |
| 蛇形排列 | 物理连接顺序与阅读顺序分离 |
| 连线可视化 | SVG 绳子连线实时跟随，绷紧 / 松弛直观可见 |
| 拖拽交互 | Pointer Events 统一鼠标 / 触摸拖拽，支持多点 |
| 快捷键 | `F` 全部解锁、文字在重力下散落；`R` 缓动恢复原位；`V`（或底部按钮）显示 / 隐藏绳子连线 |
| 自定义文本 | 底部输入框输入任意文本，回车即重建文字 |

## 📖 快速开始

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需构建。

修改文件顶部 `CONFIG` 对象即可定制文本、字号、重力、阻尼、解锁阈值等参数，无需改动物理代码。

## 🧰 技术栈

- 原生 HTML + CSS + JavaScript（零依赖，单文件）
- Verlet 积分 + 距离约束 + 圆形碰撞检测（120Hz 物理循环 + rAF 渲染）
- SVG 连线可视化
