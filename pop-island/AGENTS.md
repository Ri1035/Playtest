# AGENTS.md — 项目协作与代码开发规范

本文件约束本仓库内所有代码与文档改动，任何协作方（人或 AI 代理）进入本仓库前先读本文件。

## 基本准则

1. **开工前先检索**：复杂或陌生任务先检索开源方案、免费资源、现有 skills，不超过 1-2 轮；简单任务直接开工。
2. **一次只完成指定任务**：不擅自扩展范围、不改动任务外文件；完成指定任务所必需的辅助动作（装依赖、本地化资源、建部署目录等）不算越界。
3. **代码规范**：命名语义化、格式统一；常量集中管理，魔法数字注明含义。
4. **去除 AI 水印**：页面不留任何"由 AI 生成"类标识；代码与注释不留默认 AI 署名或生成痕迹。
5. **密钥安全**：token / 密钥一律走环境变量，禁止硬编码进代码、文档或提交记录。
6. **自验证并报告**：每次改动后运行构建/lint/测试，报告结果；禁止臆造功能、跳过验证或假装完成。
7. **Git 规范**：小步提交、提交信息清晰（见下文），版本管理与日志记录在每次任务结束前检查。

## 技术栈

- 纯原生 JavaScript（ES Modules）+ Canvas 2D，无运行时依赖
- Vite 5 负责开发服务器与构建
- 部署：GitHub 管理仓库 + Cloudflare Pages（构建命令 `npm run build`，产物目录 `dist`，合入 `main` 即部署）

## 常用命令

```bash
npm install     # 安装依赖
npm run dev     # 本地开发
npm run build   # 生产构建 -> dist/
npm run preview # 本地预览构建产物
```

## 提交信息规范

采用 Conventional Commits 风格：

- `feat:` 新功能 / 玩法
- `fix:` 缺陷修复
- `refactor:` 重构（行为不变）
- `perf:` 性能优化
- `docs:` 文档
- `chore:` 构建、工具链、依赖等杂项
- `style:` 样式 / 格式

示例：`feat: 新增磁铁道具与冰冻道具`、`fix: 修复移动端摇杆松手后卡死`
