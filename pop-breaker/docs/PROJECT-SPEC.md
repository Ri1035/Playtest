# PROJECT-SPEC.md — 项目定位、产品目标与功能范围

## 定位

一款以波普艺术（Pop Art）为视觉语言、零外部素材的 Web 2D 打砖块街机游戏，可直接在浏览器游玩，移动端与桌面端均可操作。

## 产品目标

1. 呈现完整可玩的打砖块玩法闭环（发球、反弹、击砖、连击、道具、过关）。
2. 用程序化渲染传达波普美学：撞色、网点、粗描边、拟声词。
3. 轻量交付：构建产物 < 60KB，无外部依赖运行时资源。

## 功能范围（v0.1.0）

- 挡板移动（鼠标 / 触摸 / 方向键）与发球（点击 / 空格）
- 砖块物理碰撞、单 / 双击砖块（钻石 2 击）
- 连击倍率（1.5s 窗口）与得分飘字
- 三种道具：加宽挡板（W）、三球（M）、减速（S）
- 6 组关卡图案 × 5 套配色轮换，速度逐关递增
- 生命 3 条、最高分本地持久化、暂停 / 静音

## 不在范围

- 多人在线、账号系统、后端服务
- 外部图片 / 音频素材
- 关卡编辑器
